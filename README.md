# Parcial moviel: gestión de albunes de fotos 
 - Realizado por Santiago Angel Sanchez 
##  Requisitos previos

- **Node.js** compatible con Angular 22: versión **22.22.3 o superior de la serie 22**, **24.15.0 o superior de la serie 24**, o **26.x**.
- **npm**, incluido con Node.js.
- El proyecto usa Angular **22.2.3**, Ionic Angular **9** y TypeScript **6.0.x**. Las versiones exactas están registradas en `package-lock.json`.

Consulta la [tabla oficial de compatibilidad de Angular](https://angular.dev/reference/versions) si necesitas verificar tu versión de Node.js.

---

## Instalar dependencias del proyecto:

- npm install
## Ejecutar el servidor de desarrollo móvil:

- npx ionic serve
## O alternativamente:
- npm start
## La aplicación se abrirá en http://localhost:8100/. Se recomienda abrir las Herramientas de Desarrollador (F12) y activar el modo de emulación de dispositivo móvil (iPhone 14 / Pixel 7).

## Compilar para producción:

- npm run build
## Ejecutar pruebas unitarias:

- npm test
